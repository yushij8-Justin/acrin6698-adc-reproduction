# Reproduction scope

This is a software replay of two historical technical analyses. It does not modify either cohort, the ROI definition, zero handling, the comparison estimand, or the original reporting threshold. The original cohorts' archived implementation and the hold-out implementation are kept separate.

| Item | Basis |
|---|---|
| Original Table 1 quantitative dispositions and Table 2 numerical results | Recomputed from the fixed DICOM series |
| Numerical points underlying Figure 2 | Recomputed locally, with package-specific labels. The set of numerical points is the comparison target. |
| Original visual ROI counts and Table 3 cross-tabulation | Published aggregate from archived physician confirmation. A software run cannot replicate the human classification. |
| Original Figure 1 | The replay supplies the technical flow counts. Its visual branch is the archived aggregate. |
| Hold-out disposition and ADC/wCV | Recomputed from the 170 available, content-verified DICOM series within the frozen 180-series attempt |
| Hold-out recovery and mapped versus stored comparison | Historical unavailable estimates. The package replays the strict pathway. It does not create adjudication evidence. |
| Clinical treatment outcomes | Outside the input and analysis scope |

The strict hold-out reader uses the released source-reference chain. The original extended metadata search and any future recovery adjudication are separate from this replay. The physical acquisition and the upstream proprietary processing that generated the released ADC maps are outside the available evidence.

All files generated by the runners belong in local output directories. In particular, original-cohort numerical figure points are local outputs and should not be added to the repository with the pairing map. Publicly released material contains no DICOM images, patient-level output tables, clinical outcome files, physician case notes, old case-label crosswalks or credentials.
